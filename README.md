# DAS LEAP Final Project - Scenario 1: Understanding Diabetes Progression

Final project for LEAP | Data Analytics and Statistics: a complete data
analysis workflow in R on the diabetes progression dataset (442 patients).

**Read the report online:** https://syaikhipin.github.io/DAS_Leap_Final/

## Contents

| File | What it is |
|------|------------|
| `final_scenario1_diabetes.R` | Complete analysis script (runs top to bottom, saves all figures to `figures/`) |
| `diabetes.tab.txt` | Dataset (442 patients, outcome + 10 baseline characteristics) |
| `figures/` | The 7 figures generated by the script |
| `output.txt` | R console transcript of the full run |
| `index.html` | The analytical report (also rendered as PDF for submission) |

## Reproduce

Open the project folder in R, then:

```r
source("final_scenario1_diabetes.R")
```

Requires `ggplot2`, `dplyr`, `broom` (installed automatically if missing).
Regenerates every number in the report and all 7 figures.

## Structure of the analysis

1. Understand and prepare the data
2. Explore the data
3. Investigate relationships
4. Build and interpret regression models (simple: bmi; multiple: bmi + bp + s5)
5. Evaluate the analysis (residuals, VIF, confidence intervals)
6. Draw appropriate conclusions (observational data, no causal claims)
